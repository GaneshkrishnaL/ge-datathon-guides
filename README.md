# Gemini Enterprise datathon guides

Setup and build guides produced for the CHS Gemini Enterprise datathon.

Click any document below to read it in the browser. GitHub renders PDFs inline,
page by page, so there is nothing to download and nothing to open in another
application.

| [Google Workspace connectors](Google_Workspace_Connectors_Setup_Guide.pdf) | 7 | Setting up Workspace data sources for Gemini Enterprise |
| [Patient pre-registration build guide](Patient_PreRegistration_Build_Guide.pdf) | 10 | Conversational SMS intake using CX Agent Studio and Twilio |

## Reading these

Each guide is self-contained and includes its own prerequisites, step by step
instructions with screenshots, and a troubleshooting table covering the failures
we actually hit while building.

The troubleshooting sections are worth reading before you start rather than
after something breaks. Several of the problems documented there produce no
error message at all.

## Notes

Every guide was written against a working build, not from documentation alone.
Where the official docs were wrong or incomplete, the guides say so and give the
correction.

Screenshots and figures reflect console versions as of August 2026. Google
renames and reorganises these consoles regularly, so menu labels may differ
slightly from what you see. The navigation paths described in words are more
durable than the screenshots.
